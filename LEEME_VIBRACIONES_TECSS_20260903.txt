CLEAR - ANALISIS DE VIBRACIONES TECSS
Fecha: 03/09/2026

OBJETIVO
Se incorporo a CLEAR el analisis estadistico del script Vibraciones.py como un
proceso desacoplado de IIS. Python consulta VIBR y GPM, calcula los resultados y
los guarda en LC_MDB. PHP solo consulta tablas locales ya procesadas.

NO SE REEMPLAZA EL MODULO 3SIGMA
La nueva pantalla "Analisis de Vibraciones" es adicional e independiente de
"3Sigma TECSS".

COMPONENTES A INSTALAR EN WINDOWS SERVER
1. Python 3.11 x64 (tambien se admite 3.10 o 3.12).
2. Microsoft ODBC Driver 18 for SQL Server. Si ya existe el Driver 17 sirve.
3. Paquetes Python: numpy, pandas y pyodbc. El instalador crea un entorno
   virtual aislado y los instala desde requirements.txt.

Python no se instala dentro de PHP ni se agrega como modulo de IIS. La tarea
puede ejecutarse en el mismo servidor o en otro equipo Windows que tenga acceso
de red a la base origen y a LC_MDB.

INSTALACION WEB Y SQL
1. Hacer copia de seguridad de los archivos actuales.
2. Copiar los archivos del parche sobre la carpeta de CLEAR respetando las
   subcarpetas.
3. Ejecutar una sola vez, sobre LC_MDB:
      SQL\CLEAR_TECSS_VIBRACIONES.sql
4. No es necesario reiniciar IIS. Recargar el navegador con Ctrl+F5.

INSTALACION DEL PROCESO PYTHON
Abrir PowerShell como Administrador dentro de:
   clear\python\vibraciones_tecss

Ejecutar:
   Set-ExecutionPolicy -Scope Process Bypass
   .\INSTALAR_VIBRACIONES_TECSS.ps1

El instalador crea:
   C:\CLEAR\VibracionesTECSS

Editar luego:
   C:\CLEAR\VibracionesTECSS\config.json

Completar las credenciales de:
- Origen: SYS_MP_YPF_LH / dbo.vwDatosEyesOnVibracionGpm.
- Destino: LC_MDB usa por defecto autenticacion de Windows contra 10.17.40.37.

CONFIGURACION DEL DESTINO CON AUTENTICACION DE WINDOWS
La seccion destination debe quedar asi:
   "destination": {
     "server": "10.17.40.37",
     "database": "LC_MDB",
     "trusted_connection": true,
     "connection_timeout": 30
   }

No se completa usuario ni contrasena SQL para el destino. La conexion utiliza
la identidad de Windows que ejecuta Python.

No guardar config.json dentro de C:\inetpub\wwwroot. El archivo contiene
credenciales y debe permanecer fuera del sitio web.

Verificar conexiones y registrar la tarea cada 15 minutos:
   .\INSTALAR_VIBRACIONES_TECSS.ps1 -RegisterTask

El instalador ejecuta primero --check. Si la vista, las tablas o las
credenciales no son correctas, no registra la tarea.

Al registrar la tarea, el instalador solicita la cuenta de Windows autorizada
en SQL Server. Usar SWPCRDLHSC051\Admin y escribir su contrasena de Windows.
La tarea queda preparada para ejecutarse aunque el usuario no haya iniciado
sesion. No utilizar SYSTEM con Trusted_Connection porque seria otra identidad.

PRIMERA EJECUCION
La primera carga toma por defecto 90 dias y puede tardar mas que las siguientes.
Las ejecuciones posteriores leen solamente desde la ultima fecha, con 2 horas
de solapamiento. La cache conserva 120 dias.

Se puede ejecutar manualmente desde:
   C:\CLEAR\VibracionesTECSS\EJECUTAR_AHORA.cmd

La tarea programada se llama:
   CLEAR - Vibraciones TECSS

MAPEO DE BATERIAS
Ya no se utiliza el Excel NOMBRES DE POZO.xlsx. El proceso busca POZO y BATERIA
en dbo.TECSS_RTQP dentro de LC_MDB. Estos nombres pueden cambiarse en
config.json si la tabla definitiva fuera otra.

FUNCIONALIDAD WEB
- Indicadores de Normal, Alerta, Critico, Exceso frecuente y Parado/Sin senal.
- Filtros por estado, bateria y pozo.
- Grilla con selector de columnas.
- Tendencia VIBR/GPM con umbrales por pozo.
- Alertas sostenidas y picos aislados.
- Comentarios por pozo.
- Exportacion Excel.
- Seleccion de filas para el modulo de reportes.
- Permisos integrados con los perfiles existentes de Telemetria TECSS.

SEGURIDAD
El script original recibido contenia usuario y clave SQL escritos directamente.
La version integrada no contiene contrasenas. Se recomienda cambiar la clave
que figuraba en el archivo original y usar una cuenta dedicada con los permisos
minimos necesarios.

La contrasena solicitada al registrar la tarea queda administrada por el
Programador de tareas de Windows y no se escribe en config.json ni en el script.

DIAGNOSTICO
- Logs Python: C:\CLEAR\VibracionesTECSS\logs
- Estado de la ultima ejecucion: parte superior de la nueva pantalla.
- Historial tecnico: dbo.CLEAR_TECSS_VIBRACIONES_EJECUCION.
- Si la pantalla indica tablas faltantes, ejecutar el SQL de instalacion.
- Si pyodbc informa que no hay driver, instalar Microsoft ODBC Driver 18 x64.
