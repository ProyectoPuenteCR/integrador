HOTFIX CPU SQL SERVER - CLEAR - 26/08/2026
============================================================

OBJETIVO
Evitar que cada pantalla de telemetría recalcule las alarmas de 24 horas
leyendo y agrupando la tabla completa dbo.FIXALARMS.

ORDEN DE INSTALACIÓN
1. Copiar la carpeta clear sobre la instalación existente.
2. Reciclar el Application Pool de CLEAR en IIS.
3. Ejecutar SQL/CLEAR_HOTFIX_CPU_TELEMETRIA_20260826.sql.
4. No ejecutar manualmente el procedimiento durante horario de uso.
   El Job existente hará la próxima actualización.
5. Abrir CLEAR y presionar Ctrl+F5.

DIAGNÓSTICO
Si SQL Server continúa con CPU alta, ejecutar:
SQL/CLEAR_DIAGNOSTICO_CPU_SOLO_LECTURA_20260826.sql
y conservar las dos primeras grillas de resultados. El script es sólo lectura.

CAMBIOS DE SEGURIDAD DE RENDIMIENTO
- Sin CREATE/ALTER de tablas desde peticiones PHP.
- Sin agregaciones de FIXALARMS desde las grillas de telemetría e inyección.
- Contadores de alarmas leídos desde TELEMETRIA_POZOS_GENERAL_CACHE.
- Comentarios de telemetría consultados al abrir el popup.
- Actualización automática desactivada por defecto.
- Job protegido contra solapamiento, con MAXDOP 1 y transacción corta.

IMPORTANTE
No reiniciar SQL Server ni limpiar el plan cache como parte de esta instalación.
La memoria mostrada por el Administrador de tareas puede ser caché normal;
el indicador principal a controlar después del hotfix es la CPU sostenida.
