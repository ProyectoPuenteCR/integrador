PARCHE CLEAR - REPORTES EN GRILLA PARA TELEMETRIA
Fecha: 01/09/2026

OBJETIVO
- Agregar un check a la izquierda de cada fila de Telemetria para incluir el estado del pozo en el reporte.
- Mostrar todo el contenido del reporte como grillas horizontales.
- Incorporar siempre la columna Comentario en el reporte.
- Corregir la exportacion a Excel de las grillas de Telemetria.

PANTALLAS CUBIERTAS
- Grilla general de pozos.
- Monitoreo Pozos.
- Telemetria PCP.
- Telemetria BES.
- Telemetria TECSS.
- 3Sigma TECSS.
- Reporte operativo, exportacion Excel y envio por correo.

INSTALACION
1. Hacer una copia de seguridad de los archivos actuales.
2. Copiar el contenido de la carpeta clear de este paquete sobre la carpeta clear de la aplicacion.
3. Conservar la estructura de carpetas y reemplazar solamente los archivos incluidos.
4. Reciclar el pool de IIS o limpiar la cache de PHP si la instalacion la utiliza.
5. Actualizar el navegador con Ctrl+F5.

BASE DE DATOS
- Este parche no incorpora scripts SQL nuevos.
- Utiliza las tablas existentes del constructor de reportes y de comentarios centralizados.

PRUEBA RAPIDA
1. Abrir cualquiera de las pantallas de Telemetria.
2. Marcar una o varias filas con el check de la izquierda.
3. Abrir Ver reporte y comprobar que las filas aparecen agrupadas en una grilla.
4. Confirmar que la ultima columna es Comentario.
5. Probar Exportar Excel con filtros activos y abrir el archivo .xls.
6. En 3Sigma TECSS, repetir la seleccion y la exportacion.

VALIDACION REALIZADA
- Sintaxis PHP 7.4: 140 archivos analizados sin errores.
- Sintaxis JavaScript: 4 archivos modificados analizados sin errores.
- Prueba PHP 7.4 de agrupacion: filas de Telemetria y series existentes convertidas correctamente a grillas con Comentario.
